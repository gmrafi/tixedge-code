# Project: Website (প্রজেক্ট: ওয়েবসাইট)
### A Dual-Engine Hybrid Educational Ecosystem for Generation Alpha

**Project: Website** is a foundational, project-oriented computational architecture field manual and live browser simulation sandbox designed for school students and beginners. Built to dismantle passive screen addiction, this ecosystem transforms learners into active digital creators and software architects through tactile print-media exercises and a zero-friction, client-side browser IDE.

## Pedagogical Architecture: The Dual-Engine Model

Modern educational research demonstrates that purely digital tutorials often result in cognitive distraction and superficial copy-pasting. Conversely, conventional classroom textbooks fail to provide immediate computational feedback.

Project: Website resolves this dilemma through a synchronized **Dual-Engine Model**:

1. **Physical Tactile Field-Manual (ট্যাকটাইল ফিল্ড-ম্যানুয়াল):**
   A structured printed workbook containing conceptual illustrations, architectural blueprints, offline pencil-and-paper tracing exercises, and bug-trap challenges.

2. **Digital Simulation Sandbox (ট্যাকটাইল ক্লাউড স্যান্ডবক্স):**
   A real-time, browser-based coding studio powered by TixEdge Code. Learners enter code without complex installation steps, local environments, or terminal configuration, observing instantaneous rendering and visual feedback.

### The Construction Simulation Metaphor
To demystify abstract programming syntax for young minds, the curriculum maps web architecture directly to tangible architectural construction:
- **Land & Boundaries (জমি ও সীমানা):** The `<html>` root structure and page layout.
- **Bricks & Walls (ইট ও দেয়াল):** Structural HTML elements (`<h1>` to `<h6>`, `<p>`, `<div>`, `<ul>`, `<ol>`).
- **Posters & Portals (পোস্টার ও প্রবেশদ্বার):** Media elements and hyperlinks (`<img>`, `<a>`).
- **Paint & Aesthetic Interior (রঙ ও সাজসজ্জা):** Cascading Style Sheets (CSS inline styling, colors, layout boxes).
- **Automation & Electricity (স্বয়ংক্রিয় ব্যবস্থা):** JavaScript behavioral logic, dynamic DOM reactivity, and state.

## Book Structure & Modules

### Volume 1: Mission 1 - Blueprint & Structure (মিশন ১: ব্লুপ্রিন্ট ও কাঠামো)
Focus: Foundational HTML Architecture and Semantic Web Engineering.
- **Chapter 1:** How Computers Listen (কম্পিউটার কীভাবে কথা শোনে?) - Comments and Instructions.
- **Chapter 2:** The Toolbox & First Brick (যন্ত্রপাতির বাক্স ও প্রথম ইট) - Elements and Tag Pairs.
- **Chapter 3:** Meet the Blocks (ব্লকের পরিচয়) - Unordered and Ordered Lists.
- **Chapter 4:** The House Blueprint (বাড়ির নকশা) - `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`.
- **Chapter 5:** Erecting the Signboards (সাইনবোর্ড বসানো) - Semantic Heading Hierarchy (`h1`-`h6`).
- **Chapter 6:** Photo Frames (ফটো ফ্রেম) - Image Embedding (`src`, `alt`, dimensional constraints).
- **Chapter 7:** Magical Doors (জাদুর দরজা) - Hyperlink Networks (`href`, `target`).
- **Chapter 8:** Wall Paint & Aesthetics (দেয়ালের রঙ) - Inline CSS Styling and Visual Styling.
- **Chapter 9 (Capstone):** Complete Portfolio Project (আমার সম্পূর্ণ প্রজেক্ট ও পোর্টফোলিও).

### Volume 2: Mission 2 - Style & Power-Up (মিশন ২: স্টাইল ও পাওয়ার-আপ)
Focus: Advanced CSS Layouts, Box Model, and JavaScript Computational Logic.

## Technical Specifications & Stack

- **Framework:** Next.js 16 (App Router architecture with React Server Components)
- **Compiler & Bundler:** Turbopack
- **Language:** TypeScript 5 with strict static typing
- **Styling & Design System:** Tailwind CSS v4 with bespoke editorial tokens
- **Typography Engine:** SolaimanLipi (Primary Bengali Serif/Sans Engine with high-contrast optical weights) + Inter + JetBrains Mono
- **Sound Synthesis:** Native Web Audio API procedural sound synthesizer (Zero external audio file overhead)
- **Iconography:** Lucide React (Clean, professional, vector-based glyphs with zero emojis)
- **Sandbox Security:** Sandboxed client-side iframe memory environment (`allow-scripts`, no tracking, zero server retention)
- **State Persistence:** Instant URL serialization with base64/compression for friction-free project sharing without database requirements
- **Parental & Educator Tools:** Integrated print worksheet generator (CSS `@media print`) and verification certificate renderer (HTML5 Canvas engine)

## Getting Started

### Prerequisites
- Node.js 18.18.0 or newer
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/gmrafi/tixedge-code.git

# Navigate to the project directory
cd tixedge-code

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to launch the studio.

### Production Build

```bash
# Generate optimized production build
npm run build

# Start production server
npm run start
```
